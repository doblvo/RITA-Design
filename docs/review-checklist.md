# Review checklist

## Visual
- [ ] Glacier/Teal/Copper tienen intención.
- [ ] Lockup proporcional, sin sombras/degradados.
- [ ] No hay copos/flechas como marca.
- [ ] No hay overflow horizontal accidental.

## Operativo
- [ ] Funciona offline y deja claro local/cloud.
- [ ] PTI solo RAPS, SHORT, LONG, CA.
- [ ] RUNNING y SUPER FREEZER no aparecen.
- [ ] CEDEX teal, repuestos Copper.
- [ ] Foto pertenece a línea y respeta máximo 5.
- [ ] PN requiere selección explícita.
- [ ] Unidad nueva limpia.

## Accesibilidad
- [ ] Icon-only con label.
- [ ] Foco visible.
- [ ] Mensajes junto al campo.
- [ ] Touch target mínimo 44 px.
