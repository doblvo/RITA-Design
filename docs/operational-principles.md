# Principios operativos

1. Primero identifica: unidad e ISO Code.
2. Nunca pierdas: persistir antes de red.
3. Hazlo corregible: catálogo/OCR proponen; la persona confirma.
4. Mantén contexto: daño + método + responsabilidad en CEDEX.
5. Separa responsabilidades: Teal para CEDEX, Copper para repuestos.
6. Explica sincronización: local, pendiente, confirmado, error.
7. Diseña para guantes: acciones directas, 44 px, poco zoom.
8. No inventes: combinación desconocida queda manual y marcada.
