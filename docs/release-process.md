# Release process

1. Cambiar tokens/contratos en una rama.
2. Actualizar docs, changelog y adaptadores.
3. Ejecutar `npm run validate`.
4. Probar showcase a 360/768/1280 px.
5. Revisar RITA Iquique y RITA Offline.
6. Publicar release semántica con notas de migración.
7. Consumidores actualizan de forma explícita; no se reemplazan APKs anteriores.
