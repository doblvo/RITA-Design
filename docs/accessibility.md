# Accesibilidad

Contraste WCAG AA; focus-visible de 3 px; labels en icon-only; errores asociados al campo; estados con color + icono + texto; orden de foco lógico; target 44 px; diálogos con foco contenido; tablas con encabezados y scroll interno.

En móvil: texto de inputs 16 px, teclado sin ocultar el campo activo y sin overflow horizontal accidental. Si falla un catálogo, no se borra el valor escrito.
