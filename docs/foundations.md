# Fundaciones

## Color

Glacier es acción y navegación; Glacier Bright es énfasis; Copper es repuesto/alerta; Ink es lectura; Slate es texto secundario; Ice es lienzo; White es superficie.

Los estados combinan color + icono + texto. Nunca uses color como única señal.

## Tipografía

- **Manrope**: títulos, cifras y personalidad.
- **Inter**: lectura, controles, formularios y tablas.
- **JetBrains Mono**: ISO 6346, ISO Code, PN, seriales y códigos.

Escala: 10, 12, 14, 16, 18, 22, 28, 36, 44 px.

## Espacio y forma

La grilla es de 4 px. Componente habitual: 16 px. Control 8 px, fila 12 px, card 16 px, hero 24 px, modal 20 px, pill 999 px. Borde 1 px. Touch target mínimo 44 px.

## Motion

Micro 120 ms, control 180 ms, panel 260 ms, easing `cubic-bezier(.2,.8,.2,1)`. Respeta `prefers-reduced-motion`.

## Responsive

compact 0–479, mobile 480–767, tablet 768–1023, desktop 1024+. Diseña primero la tarea móvil: desktop añade densidad, no cambia el modelo mental.
