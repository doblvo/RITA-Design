# Migración desde Sites

Este repo es el destino permanente de la librería. Sites no forma parte del runtime ni del proceso de publicación.

Se conserva el índice de foundations, marca, componentes, iconos, evidencia, sincronización y plantillas, junto con Glacier/Teal/Copper, Manrope/Inter/JetBrains Mono y ejemplos reefer.

Ahora cada decisión vive en archivos versionados, con tokens CSS/TS/Dart, contratos explícitos y CI. No se copian catálogos completos, datos reales, fotos, secretos ni endpoints.
