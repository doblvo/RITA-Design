# Plataformas

## Web/PWA

Importa `tokens/tokens.css`. React, Tailwind, shadcn o CSS propio son implementación; la semántica RITA permanece.

## Flutter

Usa `tokens/tokens.dart` y `flutter-theme.dart`. Material 3 recibe la geometría y tipografía RITA.

## Compatibilidad mínima

Probar 360, 768 y 1280 px; teclado abierto; offline; lector de pantalla; foco visible; alto contraste; tablas con scroll interno.
