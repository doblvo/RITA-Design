# Contribuir

Antes de cambiar algo, identifica si afecta marca, token, componente, patrón o dominio; comprueba RITA Offline/Iquique; y revisa offline, teclado móvil, accesibilidad y sincronización.

Convenciones: tokens kebab-case/--rita-*, estados explícitos, copy operativo, 44 px mínimos, no “STS” visible, no PN automático y scroll horizontal solo dentro de la tabla que lo necesita.

Un PR incluye problema operativo, superficies afectadas, screenshot/HTML si cambia UI, impacto Flutter/web, `npm run validate` y notas de migración.
