# Dominio reefer

El dominio cambia la forma de los componentes.

- Unit: ISO 6346;
- PTI: tipo de inspección;
- CEDEX line: componente, ubicación, daño, método, responsabilidad;
- Part: PN, cantidad y unidad;
- Evidence: fotos por línea;
- Sync record: estado local, servidor y revisión.

Contratos: [PTI](pti-mappings.json), [CEDEX](cedex-schema.json), [Part rules](part-rules.json), [Status](status-model.json), [Catalog](catalog-contract.md), [Validation](validation-matrix.md).
