# @rita/icons

El paquete futuro expondrá iconos por nombre semántico. El mapa canónico está en [icons/registry.json](../../icons/registry.json).

Ejemplo de API prevista:

```ts
<RitaIcon name="cedex" label="ISO Code / CEDEX" />
<RitaIcon name="cloud-off" label="Sin conexión" />
```

El proveedor visual puede cambiar, pero los nombres RITA y sus labels permanecen.
