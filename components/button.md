# Button

| Variante | Uso |
| --- | --- |
| Primary | abrir, guardar, sincronizar, finalizar |
| Secondary | volver o acción complementaria |
| Quiet | acción dentro de fila |
| Danger | eliminar o acción destructiva |

Estados: default, hover, focus-visible, pressed, disabled, loading y offline. Loading mantiene el ancho; offline no equivale a disabled porque guardar localmente sigue siendo válido.

Copy directo: **AGREGAR ESTE REPUESTO**, **GUARDAR COMO PENDIENTE**, **SINCRONIZAR AHORA**.
