# Photo Evidence

Cada foto se asocia a `unitId + damageId`. Máximo cinco por línea ISO Code.

Estados: local, queued, uploading, online, failed. Incluye miniatura, contador 3/5, cámara/galería y reintento. No uses antes/después si el dominio solo conoce una línea ISO. No envíes automáticamente a OCR.

Optimización sugerida: lado máximo 1280 px, JPEG calidad aproximada .86 y copia local hasta confirmación.
