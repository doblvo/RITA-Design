# Componentes

No son una colección genérica: cada componente representa una tarea de campo y debe poder explicar dato, estado y recuperación.

## Anatomía común

Etiqueta visible, valor/acción, helper si reduce error, estado semántico, target 44 px, foco visible y comportamiento offline cuando aplique.

## Jerarquía

Captura → dominio → evidencia → sincronización → navegación/overlays → feedback.
