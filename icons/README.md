# Iconografía

Iconos lineales, técnicos y legibles en 16/20/24/32 px. [registry.json](registry.json) mantiene nombres RITA, aliases y etiquetas accesibles.

## Familias

action, navigation, domain, evidence, capture, sync, status, people y security.

## Reglas

- icono + texto para estados críticos;
- icon-only siempre con label accesible;
- no usar nube para afirmar sincronización cuando el dato solo está local;
- no usar flechas/copo como sustituto del símbolo de marca;
- botones móviles de icono: 44 × 44 px;
- el proveedor puede ser Lucide/Material/propio, pero el significado se consume desde el nombre RITA.
